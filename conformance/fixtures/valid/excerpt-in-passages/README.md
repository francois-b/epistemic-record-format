# excerpt-in-passages

`ERF-69`: an excerpt is a sequence of passages. The normalized text holds
two passages of one work, separated by a paragraph consisting only of the
elision marker `[...]`, which says material was skipped there. One atom
quotes inside each passage and both pass the quote check; the marker is a
paragraph separator under `ERF-51`, so no span can cross it. Ruled
2026-08-26 (B-60).
