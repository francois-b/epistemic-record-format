# Lane 3: the scale corpus

**The corpus this lane produced is not here. It is `stress-tests/ai-capex/`,
a working corpus in its own right rather than a test artifact.** This folder
holds the lane's process record: the friction log of every run, in
execution order, plus the cross-vendor audit log.

Lane 3 asked what falls apart at real scale. It ran as eleven sequential
agents rather than one, each reading the corpus its predecessors left and
adding to it, because no single context authors 151 records with real
fetching, and because several hands in sequence is the condition under
which conventions drift. The numbered logs are that story in order:

| Run | What it did |
|---|---|
| 01, 02 | Source scouts, the debate's two camps, in parallel |
| 03, 04, 05 | Atom batches over the captured sources |
| 06 | A third scout: the dimensions both camps ignore |
| 07, 08 | Atom batches over the new sources, to the scale floor |
| 09, 10 | Claim batches: the debate core, then everything beyond it |
| 11 | The closing author: surveys and narratives |
| 12 | Cross-vendor finding audits (Gemini, DeepSeek, via `mods`) |

Read them in order and the drift is legible: date conventions diverging
between batches, grading philosophy resolving toward the spec's literal
table by batch 5, and the closing retrospective's finding that all 151
records name the same author because the actor grammar cannot tell two
instances of one model apart.
