There is no diff for arguments: no mechanical primitive that shows what changed between two versions of an argument

## Working notes

The most interesting near-miss in the corpus. Argument mapping is a
field with a literature and a vocabulary; Argdown writes argument
structure as plain text inside markdown, which a line diff handles today;
Kialo runs claim trees at scale. And still nothing found computes or
presents a structural difference between two versions of an argument.
The sentence is false as written and close to true as meant, and the
author should say the true version.
