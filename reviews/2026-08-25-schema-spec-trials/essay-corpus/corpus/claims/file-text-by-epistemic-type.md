Knowledge-work tools should file text by epistemic type, distinguishing a captured source, a verified fact, an asserted claim, an argument over claims, a position held, an open question, and a ruling

## Working notes

Seven types are asserted as different things. The corpus records that at
least three of the seven (source, claim, argument) are typed in existing
systems (nanopublications, Discourse Graphs, argument maps); the ruling
and the position held were found nowhere.
