**PROV** is a set of recommended standards of the [World Wide Web Consortium](https://en.wikipedia.org/wiki/World_Wide_Web_Consortium "World Wide Web Consortium").^([\[1\]](#cite_note-1)) These include its data model,^([\[2\]](#cite_note-2)) an [XML](https://en.wikipedia.org/wiki/XML_schema "XML schema") schema for that model, an [OWL2](https://en.wikipedia.org/wiki/Web_Ontology_Language "Web Ontology Language") ontology mapping that model to [RDF](https://en.wikipedia.org/wiki/Resource_Description_Framework "Resource Description Framework"), and a mapping from that ontology to [Dublin Core](https://en.wikipedia.org/wiki/Dublin_Core "Dublin Core"). It also includes a notation standard for [provenance](https://en.wikipedia.org/wiki/Provenance "Provenance") that is easy for humans to read; methods for accessing and querying prov; and a few other subspecifications.^([\[3\]](#cite_note-:0-3))

The PROV standard defines a data model, serializations, and definitions to support the interchange of provenance information on the Web.^([\[3\]](#cite_note-:0-3)) Here *provenance* includes all "information about entities, activities, and people involved in producing a piece of data or thing, which can be used to form assessments about its quality, reliability or trustworthiness".

## PROV model overview

\[[edit](/w/index.php?title=W3C_Prov&action=edit&section=1 "Edit section: PROV model overview")\]

The core concepts defined by the PROV Model are the *entity*, *activity* and *agent*.^([\[4\]](#cite_note-4)) The remaining concepts are relationships between these (e.g. *Derivation*, *Usage*, *Generation*) or specializations (e.g. *Person*, *Collection*, *Plan*).
