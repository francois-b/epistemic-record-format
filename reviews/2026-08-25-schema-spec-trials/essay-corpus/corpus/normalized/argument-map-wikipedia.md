An **argument map** or **argument diagram** is a visual representation of the structure of an [argument](https://en.wikipedia.org/wiki/Argument "Argument"). An argument map typically includes all the key components of the argument, traditionally called the *[conclusion](https://en.wikipedia.org/wiki/Logical_consequence "Logical consequence")* and the *[premises](https://en.wikipedia.org/wiki/Premise "Premise")*, also called *contention* and *[reasons](https://en.wikipedia.org/wiki/Reason_(argument) "Reason (argument)")*.^([\[1\]](#cite_note-1)) Argument maps can also show [co-premises](https://en.wikipedia.org/wiki/Co-premise "Co-premise"), [objections](https://en.wikipedia.org/wiki/Objection_(argument) "Objection (argument)"), [counterarguments](https://en.wikipedia.org/wiki/Counterargument "Counterargument"), [rebuttals](https://en.wikipedia.org/wiki/Rebuttal "Rebuttal"), [inferences](https://en.wikipedia.org/wiki/Inference "Inference")**,** and [lemmas](https://en.wikipedia.org/wiki/Lemma_(logic) "Lemma (logic)"). There are different styles of argument map but they are often functionally equivalent and represent an argument's individual claims and the relationships between them.

Argument maps are commonly used in the context of teaching and applying [critical thinking](https://en.wikipedia.org/wiki/Critical_thinking "Critical thinking").^([\[2\]](#cite_note-2)) The purpose of mapping is to uncover the logical structure of arguments, identify unstated assumptions, evaluate the support an argument offers for a conclusion, and aid understanding of debates. Argument maps are often designed to support deliberation of issues, ideas and arguments in [wicked problems](https://en.wikipedia.org/wiki/Wicked_problem "Wicked problem").^([\[3\]](#cite_note-3))

An argument map is not to be confused with a [concept map](https://en.wikipedia.org/wiki/Concept_map "Concept map") or a [mind map](https://en.wikipedia.org/wiki/Mind_map "Mind map"), two other kinds of [node–link diagram](https://en.wikipedia.org/wiki/Graph_(discrete_mathematics) "Graph (discrete mathematics)") which have different constraints on nodes and links.^([\[4\]](#cite_note-4))

## Key features

\[[edit](/w/index.php?title=Argument_map&action=edit&section=1 "Edit section: Key features")\]

A number of different kinds of argument maps have been proposed but the most common, which Chris Reed and Glenn Rowe called the *standard diagram*,^([\[5\]](#cite_note-ReedRowe64-5)) consists of a [tree structure](https://en.wikipedia.org/wiki/Tree_structure "Tree structure") with each of the reasons leading to the conclusion. There is no consensus as to whether the conclusion should be at the top of the tree with the reasons leading up to it or whether it should be at the bottom with the reasons leading down to it.^([\[5\]](#cite_note-ReedRowe64-5)) Another variation diagrams an argument from left to right.^([\[6\]](#cite_note-6))

According to [Douglas N. Walton](https://en.wikipedia.org/wiki/Douglas_N._Walton "Douglas N. Walton") and colleagues, an argument map has two basic components: "One component is a set of circled numbers arrayed as points. Each number represents a proposition (premise or conclusion) in the argument being diagrammed. The other component is a set of lines or arrows joining the points. Each line (arrow) represents an inference. The whole network of points and lines represents a kind of overview of the reasoning in the given argument..."^([\[7\]](#cite_note-7)) With the introduction of software for producing argument maps, it has become common for argument maps to consist of boxes containing the actual propositions rather than numbers referencing those propositions.

There is disagreement on the terminology to be used when describing argument maps,^([\[8\]](#cite_note-8)) but the *standard diagram* contains the following structures: *dependent premises*, *independent premises*, and *intermediate conclusions*.
