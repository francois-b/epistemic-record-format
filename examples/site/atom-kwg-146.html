Finding

RAGAS's faithfulness metric decomposes one response into claims and checks each against the retrieved context per evaluation call — a per-response metric, not a check that runs over a maintained document.

Quote

The Faithfulness metric measures how factually consistent a response is with the retrieved context. It ranges from 0 to 1, with higher scores indicating better consistency. A response is considered faithful if all its claims can be supported by the retrieved context.

RAGAS documentation, "Faithfulness" · https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/
